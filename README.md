# QA Automation Challenge

Automation framework developed using Cypress and JavaScript for frontend E2E and API testing.

## Technologies

- Cypress
- JavaScript
- Node.js
- Faker

---

## Project Structure

```bash
cypress
│
├── e2e
│   ├── api
│   └── frontend
│
├── fixtures
├── pages
├── services
├── support
└── utils
```

---

## Implemented Scenarios

### Frontend E2E

- User login
- User registration
- Product registration

### API Testing

- Create user
- Login API
- Get products

---

## Design Patterns

- Page Object Model (POM)
- Service Layer
- Custom Commands
- Dynamic Test Data

---

## Installation

```bash
npm install
```

---

## Run Cypress

```bash
npx cypress open
```

---

## Run Tests Headless

```bash
npx cypress run
```
